# 움직이는 PNG

평범한 PNG 한 장 속에 동영상이나 움직이는 장면을 숨기고, 다시 깨워서 재생하는 실험.

그림 보기 프로그램에서는 멈춘 사진으로 보이지만, **숨은그림 보기** 프로그램이나 **크롬 확장**으로 보면 그 자리에서 움직인다.

## 숨기는 방식

| 방식 | 숨기는 곳 | 살아남는 곳 | 지워지는 곳 |
|---|---|---|---|
| 화소 모드 | RGB 색값의 하위 1~2비트 | 원본 전송, PNG를 다시 저장만 하는 사이트(메타데이터 지움) | JPEG/WEBP 변환, 크기 줄이기 |
| 덧붙이기 모드 | PNG 끝(IEND) 뒤에 ZIP | 원본 그대로 주고받을 때 (반디집·7-Zip으로도 열림) | 다시 저장하는 모든 곳 |
| 숨은 장면 (MOVE) | 하위 2비트 + 직접 만든 조각 `mOVe` | 화소 모드와 같음 | 화소 모드와 같음 |

화소 모드는 색값이 최대 3만큼만 바뀌어 눈으로 구별되지 않는다. 숨길 자료가 크면 겉그림을 자동으로 키운다. 사진 크기는 대략 동영상의 1.5배.

### 화소 모드 배치

RGB 값을 왼쪽 위부터 `R,G,B,R,G,B…` 한 줄로 늘어놓는다 (알파는 쓰지 않음).

- 앞 96개 값의 하위 1비트 = 머리말 12바이트
  `'SG'` · k(값당 비트 수 1~4) · 0 · 본문 길이(4바이트, 큰쪽 먼저) · 본문 CRC32(4바이트)
- 97번째 값부터 하위 k비트 = 본문 (비트 순서는 큰쪽 먼저)
- 본문 = 이름 길이(1) · 이름(UTF-8) · 형식 길이(1) · 형식(MIME) · 자료

CRC가 맞지 않으면 망가진 것으로 보고 무시한다.

## 구성

```
1_숨은그림보기/   PC 프로그램 (Python + PySide6)
2_크롬확장/       웹페이지의 PNG를 살펴보고 숨은 동영상을 그 자리에서 재생
3_시험용/         예시 사진 3장, 시험 영상, 시험 페이지
4_옛도구/         처음 만든 명령줄 도구들
시험순서.txt      처음부터 끝까지 시험하는 순서
```

## 숨은그림 보기

```
pip install PySide6 numpy
python 1_숨은그림보기/soomgeurim.py [사진.png]
```
(윈도우는 `실행.bat` 두 번 클릭, 실행파일은 `exe로_만들기.bat`)

- PNG를 끌어다 놓으면 숨은 것(글 조각, EXIF, 직접 만든 조각, 덧붙은 ZIP, 화소 속 파일, 숨은 장면)을 목록으로 보여 주고 재생
- [꺼내기]로 원래 파일 저장
- 동영상을 끌어다 놓으면 화소 모드 사진으로 만들기
- 파일 메뉴: 덧붙이기 모드로 만들기, 아무 파일이나 원하는 겉그림 화소에 숨기기
- 윈도우: PNG 오른쪽 클릭 메뉴에 "숨은그림 보기로 열기" 등록 (현재 사용자만, 관리자 권한 필요 없음)

## 크롬 확장

`chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → `2_크롬확장`

- 화소 모드와 덧붙이기 모드 사진을 찾아 `<video>`로 바꿔서 소리 없이 반복 재생
- 디스코드는 미리보기(줄이고 WEBP로 바꾼 그림) 대신 원본 첨부파일 주소를 읽음
- 다른 사이트 그림은 백그라운드에서 받아 `createImageBitmap(colorSpaceConversion: "none")`으로 화소를 그대로 읽음
- 디스코드 앱(일렉트론)에서는 작동하지 않음, 크롬 웹에서만

## 앞으로 해 볼 것

- JPEG 변환에도 버티는 방식 (8×8 덩어리 + 오류 보정, 몇 KB 한계)
- 숨은 장면(MOVE)을 확장에서도 재생
- GIF나 그림 여러 장으로 숨은 장면 만들기
