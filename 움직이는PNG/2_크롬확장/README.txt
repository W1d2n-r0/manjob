잠든 그림 깨우기 - 크롬 확장 (시험판 0.2)

설치
 1. 이 폴더(extension)를 압축 풀어 둔다.
 2. 크롬 주소창에 chrome://extensions 입력
 3. 오른쪽 위 "개발자 모드" 켜기
 4. "압축해제된 확장 프로그램을 로드합니다" -> 이 폴더 선택
 5. 내 컴퓨터 파일에서도 쓰려면: 확장 "세부정보" -> "파일 URL에 대한 액세스 허용" 켜기

하는 일
 - 웹페이지의 PNG를 받아 보고, 숨은 동영상이 있으면 그 자리에서 소리 없이 반복 재생한다.
   · 화소 모드 (숨은그림 보기 0.2로 만든 사진) — 메타데이터를 지우는 사이트에서도 됨
   · 덧붙이기 모드 (IEND 뒤 압축파일)
 - 디스코드: 미리보기 그림(줄이고 WEBP로 바꾼 것) 대신 원본 첨부파일 주소를 찾아서 읽는다.
 - 그림이 링크로 감싸져 있으면 링크 쪽 원본 PNG도 시도한다.
 - 내 컴퓨터의 PNG를 크롬 창에 끌어다 놓아도 깨어난다(위 5번 필요).

주의
 - 시험판이라 PNG처럼 보이는 그림은 전부 한 번씩 내려받아 본다. 무거운 사이트에서는 꺼 두기.
