숨은그림 보기 0.2 — PNG 속에 숨은 것을 찾아 보여 주는 프로그램

시작
  · Python 3.10 이상이 깔려 있으면 "실행.bat" 두 번 클릭 (처음엔 PySide6를 내려받느라 조금 걸림)
  · 실행파일(.exe)로 만들려면 "exe로_만들기.bat" → dist\soomgeurim.exe

쓰는 법
  · PNG를 창에 끌어다 놓거나 [열기]
  · 오른쪽 목록에 찾은 것이 나오고, 움직일 수 있는 것이 있으면 바로 재생
  · 목록에서 고르고 [꺼내기] (두 번 클릭해도 됨) → 원래 파일로 저장
  · 동영상을 창에 끌어다 놓으면 → 화소 모드로 사진 생성 (표지 장면 화소 속에 동영상 통째로)
  · 파일 메뉴
      - 동영상을 사진으로 — 화소에 숨기기   : 메타데이터를 지우는 사이트에서도 살아남음 (기본)
      - 동영상을 사진으로 — 뒤에 덧붙이기   : 파일이 원본 그대로 전달될 때만 (반디집으로도 열림)
      - 아무 파일이나 그림 화소에 숨기기     : 겉그림을 직접 고름
  · 화소 모드는 숨길 자료가 크면 겉그림을 자동으로 키움 (채널당 하위 1~2비트만 써서 눈으로는 구별 안 됨)
    사진 크기 ≈ 동영상의 1.5배. 디스코드 무료 계정은 10MB까지 올라감
  · 윈도우 → "탐색기 메뉴에 등록" → PNG 오른쪽 클릭에 "숨은그림 보기로 열기" 생김
    (현재 사용자에게만, 관리자 권한 필요 없음. 윈도우 11은 "더 많은 옵션 표시" 안)

찾는 것
  · 글 조각(tEXt/zTXt/iTXt), EXIF, APNG 표시
  · PNG 규칙에 없는 직접 만든 조각 (예: mOVe)
  · IEND 뒤에 붙은 압축파일 — 목록 표시, 동영상이면 재생
  · 화소 하위 2비트에 숨긴 장면들
  · 화소 하위 비트에 숨긴 파일 (화소 모드, CRC로 망가졌는지 검사)

어디서 살아남나
  · 살아남음: 원본 파일 그대로 주고받기, PNG를 다시 저장만 하는 곳(메타데이터 지움)
  · 지워짐: JPEG·WEBP로 바꾸거나 크기를 줄이는 곳
